## Поддержка документации

При изменении поведения обновляйте документацию в той же поставке:

| Изменение | Документы |
| --- | --- |
| Маршрут, DTO, код ошибки, права | `specifications/03-api.md`, схемы и справочник функции |
| Таблица, связь, миграция | `specifications/02-data-model.md`, инструкции обновления и восстановления |
| Экран, состояние, синхронизация | `specifications/04-frontend.md`, пользовательский справочник |
| Планировщик или внешняя доставка | `specifications/05-jobs-and-integrations.md`, инструкции оператора |
| Конфигурация, запуск, секреты | `17-portable-operations.md`, `09-operations-runbook.md` |
| Проверка качества или ограничение | `04-quality-and-acceptance.md`, `10-known-limitations.md` |

Публикуйте действующие инструкции и ограничения без журналов разработки, выполненных этапов, персональных путей, реальных ключей и адресатов. Проверяйте относительные ссылки и примеры команд. Отчёты конкретного прогона не заменяют описание поведения и не включаются в эту документацию.
