# Тестовая песочница

В управляемом Aion многопроектная песочница запрещена: API возвращает `409 LOCAL_PANEL_REQUIRED`. Для безопасной ручной проверки создайте отдельную установку через Ouroboros. Рабочий проект не очищайте для подготовки демонстрации.

В режиме разработки (`APP_MANAGED=false`) административная песочница доступна внизу настроек. Маршруты имеют префикс `/api/v1/admin/sandbox`, требуют администратора и предназначены для изолированной среды.

| Маршрут | Назначение |
| --- | --- |
| GET /workspace | Зарегистрированный демо-проект, счётчики и тестовые аккаунты |
| GET /checks, GET /scenarios | Доступные группы и сценарии из текущего кода |
| POST /run | Запуск ключа сценария, `full_check` или `check:...` |
| GET /runs | Последние результаты |
| GET /telegram | Просмотр журнала предполагаемых сообщений |
| POST /reset | Очистка зарегистрированного демо-проекта с явным подтверждением |

Полный состав проверок определён в `backend/app/services/sandbox_checks.py`; каталог API актуальнее сохранённых названий групп. Сценарии подготовки данных не являются приёмочными тестами функций.

Очистка сверяет маркер проекта, создаёт защитную SQLite-копию, перемещает документы в архив и сохраняет общие аккаунты/роли. Проверяется отсутствие опасных межпроектных связей. Одновременные операции отклоняются `SANDBOX_BUSY`. Архивы очистки содержат всю базу и требуют такого же ограничения доступа, как исходные данные.

Для поддержки используйте в первую очередь [автоматические проверки](08-development-guide.md) и [сквозной сценарий](04-quality-and-acceptance.md). Песочница не заменяет Docker-приёмку, браузер и реальную проверку сети.
